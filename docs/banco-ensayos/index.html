Restricciones de migración a .docx (no cambiar sin aprobación)

  1. Cada protocolo (DQ/IQ/OQ/PQ) = un documento .docx independiente. Nunca un solo documento combinado. Cada .docx lleva su propio bloque de responsabilidades, su índice y sus ensayos con su numeración 1..N.
  2. Los IDs fijos (ALM-OQ-003) son las claves: nunca se renombran ni reutilizan; la numeración visible 1..N es solo presentación.
  3. Los atributos data-fase / data-cond / data-resumen definen qué ensayos entran en cada .docx según filtros (almacén + condición).
  4. Las marcas dinámicas (.rango / .equipo / .cond / .lista-resumen) se resuelven a texto fijo al generar el .docx.
